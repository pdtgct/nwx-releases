Smarter Detection
This release adds intelligent network change detection, Wi-Fi 7 MLO support, and Ethernet switch discovery.
What's New
Smart Network Change Detection
- Gateway MAC fingerprinting — Distinguishes real network changes from DHCP renewals, BSSID roams, and interface switches
- No more false flashes — Eliminates spurious "Checking..." UI flashes on transient events
Wi-Fi 7 MLO
- Multi-Link Operation detection — Identifies MLO with per-link channel and bandwidth
Radio Environment Analysis
- BSS Load IE parsing — Channel utilization and station count from access point beacons
LLDP Switch Discovery
- Switch and port identification — Discovers Ethernet switch name and port via LLDP frames (requires Npcap)
TCP Probes
- TCP connection probes — New probe type alongside existing ICMP and HTTP/HTTPS
TLS Certificate Details
- Full TLS info — Extracts complete certificate details via WINHTTP_SECURITY_INFO
Changes
- Removed status bar — WebView2 now fills the full client area
- Simplified channel/bandwidth display in WiFi detail panel
Fixes
- Anycast GeoIP handling for CDN and DNS resolver IPs
- BSS fallback channel matching and IE offset calculation
- UI hover jitter in topology segment detail panel
- Ethernet detail section not showing when connected via wire
Requirements
- Windows 11 (build 22621 or later)
- WebView2 Runtime (included in Windows 11)
